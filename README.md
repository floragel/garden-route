# Garden Route Escapes 🇿🇦

A professional, minimalist, and premium travel agency website designed specifically for an **English Class Project**. This site showcases the beauty of South Africa's iconic Garden Route through immersive storytelling, authentic photography, and high-end interactive features.

## ✨ Project Highlights

-   **Premium Minimalist Design**: A clean, modern aesthetic focusing on whitespace and high-quality visuals.
-   **Interactive Itineraries**: Custom-built vertical timelines for every package, detailing activities, luxury accommodations, and local experiences.
-   **Real-time Search Filter**: A live destination and package search bar that allows users to find their perfect trip instantly.
-   **Authentic Travel Data**: Curated information on **Wilderness**, **Knysna**, and **Plettenberg Bay**, including local landmarks and cultural highlights (like the traditional South African Braai).
-   **Modern UX/UI**: Scroll-reveal animations, smooth transitions, and responsive grid layouts (3 cols on desktop, 2 on tablet, 1 on mobile).

## 🛠️ Built With

-   **HTML5 & CSS3**: Semantically structured for SEO and accessibility.
-   **Vanilla JavaScript**: Custom logic for search filtering, modal itinerary generation, and scroll animations (Intersection Observer).
-   **Google Fonts**: Montserrat & Poppins for an elegant typographic hierarchy.
-   **Ionicons**: Sleek, modern iconography.

## 📁 Key Features

### 📅 Day-by-Day Timelines
Each travel package opens a detailed modal featuring a vertical timeline. These itineraries include:
-   **Bolded Landmarks** and *italicized* activity highlights.
-   Embedded images for every day of the journey.
-   Clickable external links to luxury hotels (e.g., Views Boutique Hotel, Kanonkop House).
-   Transparent pricing and logistics.

### 🖼️ Rich Media Gallery
A curated photo gallery featuring authentic South African landscapes and activities, with premium "lift and zoom" hover effects.

### 🔍 Smart Search
A header-integrated search overlay that filters through popular destinations and travel packages in real-time.
